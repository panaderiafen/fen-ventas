**Dónde va:** repo **fen-ventas** en GitHub (Add file → Upload files, todo el contenido del zip, Commit). Ojo: es el repo de la caja, no el de Sistema Fën.

## Qué cambia
- **Barros: nada.** Sigue imprimiendo el sobre como siempre.
- **Tablet de Ainavillo:** en el "Texto para el sobre" (al cerrar con retiro) hay una casilla nueva: **"Este equipo imprime el sobre en la impresora de etiquetas (Bluetooth)"**. Se marca **una sola vez, solo en esa tablet**.
- Con la casilla marcada, **Imprimir etiqueta** imprime directo la etiqueta de 80 × 50 mm (logo, sucursal, fecha, monto en grande, quién cerró y firma), sin abrir ninguna app. La primera vez de cada día Chrome pide elegir "BlueTooth Printer".
- Las comandas siguen igual en todos los equipos.
